# I18N Review

The following Telugu strings were written as drafts and require review by a native Telugu speaker. 

## UI Elements (index.html)
- `లెటర్ బడ్డీ` (Letter Buddy)
- `కెమెరాతో ఫోటో తీయండి` (Take photo)
- `దయచేసి వేచి ఉండండి...` (Reading...)
- `మళ్ళీ ప్రయత్నించండి` (Try Again)
- `ఇది మోసం (స్కామ్) అయ్యే ప్రమాదం ఉంది!` (WARNING: Scam signals detected)
- `ఇది ముఖ్యమైన కాగితం. మీ ఇంట్లో వాళ్లకు చూపించండి!` (Show this to a trusted contact)
- `చదివి వినిపించండి` (Read to me)
- `పంపిన వారు` (From)
- `చేయవలసిన తేదీ` (Deadline)
- `మొత్తం` (Amount)
- `మందుల వివరాలు` (Doses verbatim)
- `గమనిక: ఈ యాప్ కేవలం సహాయం కోసం మాత్రమే. ముఖ్యమైన పనులకు ఇతరుల సహాయం తీసుకోండి.` (Note: App is for assistance only. Verify important actions.)
- `ఈ లెటర్ ని మర్చిపో` (Forget this letter)

## Error Messages (config.py)
- `error`: `సిస్టమ్ లోపం. దయచేసి మళ్ళీ ప్రయత్నించండి.` (System error. Please try again.)
- `blurry`: `ఫోటో సరిగ్గా లేదు, అక్షరాలు కనపడటం లేదు. దయచేసి మళ్ళీ తీయండి.` (Photo is blurry, characters are not visible. Please take it again.)
- `dark`: `వెలుతురు సరిపోవడం లేదు. వెలుతురులో మళ్ళీ ఫోటో తీయండి.` (Not enough light. Please take a photo in the light again.)
- `cutoff`: `లెటర్ మొత్తం కనపడేలా మళ్ళీ ఫోటో తీయండి.` (Please take a photo again so the entire letter is visible.)
